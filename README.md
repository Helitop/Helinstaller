# ⚙️ Helinstaller — Ультимативный комбайн для настройки Windows

![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-blue?style=flat-square&logo=windows)
![Architecture](https://img.shields.io/badge/Architecture-x64-lightgrey?style=flat-square)
![License](https://img.shields.io/badge/License-Proprietary-red?style=flat-square)

**Helinstaller** — это многофункциональный инструмент "всё-в-одном" для установки чистых программ, тонкой настройки операционной системы, создания загрузочных флешек и мониторинга железа. Создан, чтобы экономить часы времени после переустановки Windows.

🌐 **[Официальный сайт проекта](https://helitop.github.io/helinstaller-web/)**

---

## 📥 Как скачать и установить

Этот репозиторий предназначен **исключительно для официальных релизов** и распространения обновлений приложения.

1. Перейдите в раздел **[Releases](https://github.com/Helitop/Helinstaller/releases/latest)** справа.
2. Скачайте файл `Helinstaller-Setup.exe`.
3. Запустите установщик (приложение автоматически обновит все необходимые компоненты и добавится в меню "Пуск").
4. *Приложение поддерживает бесшовные автообновления: новые версии будут скачиваться и устанавливаться в фоне.*

## 🚀 Основные возможности

### 📦 Центр чистой установки (WinGet & MS Store)
Забудьте про поиск программ в браузере и снятие галочек с «Яндекс.Браузера» в установщиках.
- Установка софта в один клик через официальные репозитории Microsoft (WinGet).
- Пакетное обновление всех установленных программ в системе (`Обновить всё`).
- Автоматический поиск актуальных MTProto-прокси для Telegram.

### 🛠️ Твики и Оптимизация системы
Легальные и безопасные скрипты для настройки Windows под себя:
- **Активация Windows и Office** (вечная цифровая лицензия через официальный метод MAS).
- **Активация WinRAR** (в один клик, без патчей и кряков).
- **Обход блокировок (Xbox DNS)** — прямой доступ к ChatGPT, Claude и Xbox Live без VPN.
- **Дезинфекция (Anti-Yandex)** — очистка системы от предустановленного рекламного мусора и смена региона рекомендаций.
- Быстрое управление UAC, брандмауэром, залипанием клавиш и интерфейсом.

### 💾 Установка Windows и Ventoy
Превратите любую флешку в мультизагрузочный инструмент:
- **Установка Ventoy** в один клик прямо из приложения (ядро скачивается напрямую с GitHub).
- Интеллектуальный поиск оригинальных ISO-образов Windows на накопителе.
- **Генератор автоустановки (OOBE Unattend)** — позволяет установить Windows 11 на старые ПК (без TPM 2.0 / SecureBoot), отключить слежку, вырезать Защитник и создать локальную учетную запись без интернета.

### 🧹 Очиститель и Анализатор диска (Debloater)
- Наглядная интерактивная диаграмма (Sunburst) для поиска самых тяжелых папок и "пожирателей места" на диске.
- Выявление и пакетное удаление мусорного ПО (Bloatware) и предустановленных OEM-утилит (McAfee, 360 Total Security, Candy Crush и др.).

### 📊 Системный монитор
Красивый дашборд с отображением:
- Нагрузки на процессор (ЦП), видеокарту (ГП) и оперативную память в реальном времени.
- Температурных датчиков железа и дисков (S.M.A.R.T.).
- Текущей скорости сети и износа батареи ноутбука.

### 📱 Экосистема
Helinstaller может работать в фоне и связываться со смартфоном через локальную сеть:
- Трансляция телеметрии ПК на телефон.
- Удаленное управление музыкой, питанием ПК и буфером обмена.
